## KMX6 V1 - first public release

**Publisher: KMX6 Project** | Windows x64 | AGPL-3.0-or-later

KMX6 combines four microphone inputs and two computer-audio sources, with two hardware mixes and four independent virtual microphones for apps such as Discord and OBS.

### Downloads

- **KMX6-V1-Setup.exe** - recommended installer. It clearly discloses and automatically downloads/installs missing Microsoft x64 runtime and USB/IP virtual-audio dependencies. Internet access, administrator approval and a restart may be required. Compatible installed components are reused.
- **KMX6-V1-Source.zip** - complete matching source snapshot, including the JUCE source tree. Source is separate from the installer and is not needed for normal use. GitHub's automatic source archives omit submodule contents.
- **KMX6-Project-Reference.pdf** - feature/reference document and benchmark summary.
- **SHA256SUMS.txt**, **release-manifest.json**, **VALIDATION.txt** - integrity information, payload inventory and verification scope.

### Included features

- Four mic source strips and two stereo computer-audio strips.
- Independent A1/A2 and B1-B4 routing, EQ, HPF, pan/balance, mute/solo and metering.
- Mic gates/limiters; eight 64-bit VST3 effect slots per source.
- Plugin Manager with standard/custom-folder scanning.
- Local latency estimates, source health counters, saved settings and repair tools.
- Uniform 25%-200% interface scaling.

### Verification and known limits

105 app checks passed, plus host/helper checks. Isolated benchmarks covered 36 cases and 1,037,904 callbacks; at 48 kHz/256 frames under contention, mean callback cost was 0.086 ms and P99 was 0.216 ms, with 7/105,696 offline calls over budget. These are not end-to-end latency measurements or a comparison with another mixer.

The app and installer are **unsigned**. Windows may show an unknown-publisher or reputation warning. Downloaded upstream installers are verified before execution; setup does not disable Windows security or change default audio devices.

Clean-PC dependency installation, reboot/sleep/device-loss recovery, broad plugin compatibility and extended soak stability remain unverified. Virtual 1 source-starvation events need investigation with a continuous known signal. Loaded effects run inside the mixer process; VST2, instruments, external sidechains and cross-channel latency compensation are not supported.
