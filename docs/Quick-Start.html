KMX6 V1

Windows x64 virtual audio mixer | Version 1.0.0 | 1 November 2026

Install

  1. Close other copies of KMX6, then run KMX6-V1-Setup.exe.
  2. Keep the default per-user location unless you have a reason to change it: %LOCALAPPDATA%\Programs\KMX6. KMX6 stores settings and logs in its writable bin folder.
  3. Setup automatically downloads and installs the required Microsoft x64 runtime and signed USB/IP driver when missing, then configures all six KMX6 virtual devices. An Internet connection is required for missing downloads (approximately 50 MB if both are needed). Components already installed or verified in the download cache are reused. If Windows asks for administrator approval, approve it to finish this one-time dependency setup.
  4. If setup requests a restart, restart Windows before launching. Otherwise launch KMX6 from the Start menu or its optional desktop shortcut.
Setup does not change your Windows default microphone or speakers. Hardware-vendor ASIO drivers, optional VB-CABLE/Hi-Fi Cable, and third-party VST3 effects are installed separately. The six KMX6 devices work without those optional cables. Windows 10 x64 build 18362 or newer is required; this release was tested on Windows 11 x64. ARM64 is not supported by this installer.

First audio route

  1. Open HARDWARE. Choose your physical headphones/interface as A1, then select its output channels. A1 controls engine timing. Use the hardware manufacturer's ASIO driver if available, or Windows Audio. The installer cannot supply drivers for every audio interface.
  2. On MIC 1 choose your physical microphone input. Begin at a moderate input level and fader level.
  3. Enable B1 on MIC 1. In Discord, OBS or your receiving app, select KMX6 Mic B1 as the microphone. A1 is your local headphone mix; B1 is the mix sent to that virtual microphone.
  4. For computer audio, choose KMX6 Computer 1 as an app's Windows playback output. It enters Virtual 1. Computer 2 enters Virtual 2. The source label shows the actual cable/device selected; an already installed supported optional cable may be preferred.
  5. Enable the A/B destinations you want on each strip, then use SAVE. Close other copies of KMX6 so they do not compete for the shared devices.

Destinations

RoutePurpose
A1 / A2Two hardware output mixes, for example headphones and speakers.
B1-B4Four virtual microphone mixes. Select the matching KMX6 Mic B device in the receiving app.

Plugins and interface

  • PLUGINS opens eight effect slots for that source. The right circle turns each effect on/off. Use the separate PLUGIN MANAGER button to scan normal VST3 locations or add a custom folder.
  • Only 64-bit mono/stereo VST3 effects are supported; plugin installers/licenses are not bundled. Live mode skips individual effects reporting more than 5 ms of delay.
  • Left-click SCALE to increase 5%; right-click to decrease 5%. Limits are 25%-200%; Ctrl+0 resets to 100%.
  • LOCAL ~... ms is a local estimate, not total microphone-to-app latency. U / D show source underrun/drop events where available. Hover for details. Idle loopback delivery can raise starvation counts without proving an audible dropout.

Dependency downloads

Downloads come from Microsoft and the official USB/IP GitHub release. Signatures are verified, and the driver SHA-256 is pinned before execution. The download cache is %LOCALAPPDATA%\KMX6\Downloads. If the Internet connection fails, retry with Repair KMX6 Audio from the Start menu. No driver installer is embedded in the KMX6 installer.

If virtual audio is missing

  1. Keep KMX6 running and wait for automatic reconnection. Check the B1-B4 link status.
  2. Click REPAIR I/O. If the runtime itself is missing and KMX6 cannot open, use Repair KMX6 Audio from the Start menu instead.
  3. Approve the Windows prompt only when you requested setup/repair. If a restart is requested, restart, launch KMX6, and rescan devices.
  4. Re-select the virtual microphone in your receiving app. A linked device may still carry silence: check the source meter, mute, plugin bypass and the B route.

Diagnostic files are under bin: dependency-setup.txt, virtual-setup.txt, virtual-reconnect.txt, audio-health.log and cable-host.log. Copy logs when reporting an issue; do not include personal plugin-state files unless you intend to share them.

The isolated benchmark covered 36 cases and 1,037,904 callbacks. It found substantial built-in DSP headroom, with intermittent live Virtual 1 starvation needing investigation. It did not measure end-to-end latency or compare another mixer. Long-session and reboot recovery are not certified.

Update or uninstall

Install a later release into the same folder to update. Your saved settings and logs are not bundled with this installer and are left in place. Uninstall KMX6 from Windows Settings to remove application files and shortcuts. User-created settings/logs and shared Microsoft/USB-IP dependencies are retained; uninstall shared dependencies separately only when no other software needs them.

Publisher and security

KMX6 and this installer are not code-signed. Windows may show an unknown-publisher warning. The bundled Microsoft runtime and USB/IP installers keep their original verified signatures. Setup never disables Secure Boot, driver signing or Windows security features.
